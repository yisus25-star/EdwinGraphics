# Imágenes de la página de inicio

Puedes personalizar la imagen principal sin editar el HTML:

1. Coloca una fotografía propia de una moto o un trabajo terminado en esta carpeta.
2. Nómbrala exactamente `hero-moto.jpg`.
3. Actualiza la página del navegador.

Ruta esperada: `frontend/assets/images/hero-moto.jpg`.

Usa una imagen horizontal, de buena resolución (idealmente 1600 × 700 px), comprimida para web. No subas imágenes con derechos de terceros sin autorización. Si el archivo no existe, el inicio conserva un fondo visual de respaldo.

Las fotos de cada producto se administran desde el panel de administrador y se guardan mediante el backend.
